# PNG Maker App 🖼️✨

A lightweight, local tool to remove backgrounds and convert photos, logos, and signatures into clean transparent PNGs.

## Features
- **AI Cutout Mode:** Powered by U²-Net (`rembg`) for people, pets, and products.
- **Signature & Document Mode:** Luminance-based extraction to preserve crisp ink strokes without blur or halos.
- **Full-Stack:** FastAPI backend with an interactive vanilla JS / HTML5 frontend.
- **Universal Input:** Accepts JPG, PNG, WEBP, BMP, and TIFF.
